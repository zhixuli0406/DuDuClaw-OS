下載 DuDuClaw OS v0.4.0

先依試用目的選桌面版或基礎版，再選 QEMU／真機目標與安裝形式。每個資產都附 .sha256 與 .minisig，寫入前請驗證並備份目標硬碟。

2026-10-16 發布 內嵌平台 1.73.4 Linux 6.18 Yocto Project 6.0 「wrynose」 Apache-2.0

下載前先知道這幾件事

  • 0.4.0 是 bring-up 版本，1.0.0 才是第一個 GA。拿來當生產環境的唯一一台機器並不合適。
  • 所有驗證都在 QEMU 完成，尚未在真實 x86-64 硬體上開機過。duduclaw-genericx86-64 這一版只建置、沒有開機。發布前在 QEMU 上，QEMU 版的整碟映像開到登入畫面（約 65 秒），兩種安裝器 ISO 開到 live 環境的自動登入（各約 125 秒）；安裝精靈這一版沒有跑。桌面版的測試映像另外跑了兩輪 rootless 驗證，第二輪 36 項過 35 項。從 v0.3.0 經 A/B 更新升到 v0.4.0、需要 LLM 憑證的完整流程、Windows 虛擬機都還沒驗證。
  • 升級是單向的：v0.4.0 起 gateway 不再以 root 執行。裝置成功開過 v0.4.0 之後，就不能再退回 v0.3.0 或更早的版本；之後的版本出問題，只能裝修好的新版或用救援開機項目。
  • SSH 預設關閉，只能從後台的維護模式打開；映像上目前沒有能透過 SSH 登入的帳號，所以這個開關只控制連接埠。
  • 開機鏈未啟用 Secure Boot 簽章，安裝前要在韌體裡關閉 Secure Boot；下載資產另有 minisign 簽章可驗證來源。dm-verity 與 TPM 也還沒啟用。
  • 目標機需要 UEFI、支援 AVX2 的 x86-64 CPU 與一顆 SSD。arm64 機器（Apple Silicon、樹莓派）不能用。
怎麼選

先選用途，再選安裝方式

試用桌面與 AI 工具鏈

選桌面版的安裝器 ISO（installer-desktop）。燒進 USB，開機跑圖形安裝精靈，選碟、確認、寫入、重開。

只要 gateway 值班機

選基礎版的安裝器 ISO（installer）。同樣的 A/B 佈局與桌面殼加 gateway，沒有應用層、AI CLI 與唯讀 root；防火牆從 v0.4.0 起與桌面版相同。這是 bring-up 產物。

想直接寫進整顆碟

選桌面版的整碟映像（.wic.zst）。解壓之後 dd 或 bmaptool 寫進目標硬碟，跳過安裝精靈。

機器維度也要選對：duduclaw-qemux86-64 是 QEMU bring-up 目標，v0.4.0 發布前整碟映像在 QEMU 開機到登入畫面、兩種安裝器 ISO 開到 live 環境的自動登入，但安裝精靈沒有跑，跑完安裝的 QEMU 紀錄仍停在 v0.1.0 與 2026-09-06 的開發版；duduclaw-genericx86-64 是真實硬體目標，在 QEMU 上開不起來，這一版只建置、沒有開機。

先驗簽再燒

確認你拿到的就是我們發布的

檔案是從 GitHub 的伺服器下載的。驗簽是你自己確認手上這份位元組，就是我們簽出去的那一份。

minisign 公鑰

六個資產同一把公鑰，v0.1.0 到 v0.3.0 也是這一把。

RWQyI00ugZ/+WVisQ2ZnKeTqFs8Ze8h2X11FO9Z8le0YubFMXYTwQD7n

驗簽章

把 <檔案> 換成你下載的檔名，同目錄要有對應的 .minisig。

minisign -V -P RWQyI00ugZ/+WVisQ2ZnKeTqFs8Ze8h2X11FO9Z8le0YubFMXYTwQD7n -m <檔案>

驗 SHA-256

同目錄要有對應的 .sha256。Linux 上把 shasum -a 256 換成 sha256sum。

shasum -a 256 -c <檔案>.sha256
燒錄

寫進 USB 或硬碟

dd 會把目標裝置整個覆蓋掉。下指令之前先用 lsblk 或 diskutil list 確認 /dev/sdX 是你要寫的那一顆。

安裝器 ISO 寫進 USB

或者用 balenaEtcher 這類圖形工具，選檔案、選隨身碟、按開始。

dd if=duduclaw-os-installer-desktop-duduclaw-genericx86-64-v0.4.0.iso \
   of=/dev/sdX bs=4M conv=fsync status=progress

整碟映像寫進硬碟

先解壓再寫。用 bmaptool copy 也可以，會跳過空區塊。

zstd -d --long=27 duduclaw-os-duduclaw-genericx86-64-v0.4.0.wic.zst
dd if=duduclaw-os-duduclaw-genericx86-64-v0.4.0.wic \
   of=/dev/sdX bs=4M conv=fsync status=progress
  1. zstd 視窗參數：映像用 --long=27 壓縮，Release 說明的解壓指令是 zstd -d --long=27，上面的範例照這個寫。
  2. 目標機開機設定：韌體切到 UEFI 開機，並且關閉 Secure Boot。v0.4.0 的開機鏈未啟用 Secure Boot 簽章，下載資產仍可驗 minisign 簽章。
  3. 安裝流程：ISO 開機後是圖形安裝精靈，選碟、確認、看寫入進度、重開。第一次開機接著跑首次設定精靈。
硬體

三個硬性條件

x86-64 且支援 AVX2

Intel Haswell（2013 年）以後、Intel N100 / N200 / N305、AMD Excavator（2015 年）以後與 Zen 全系。arm64 機器不能用。

UEFI 開機

安裝前在韌體裡關閉 Secure Boot。

SSD

最低 4 GB 記憶體與 64 GB SSD；建議 8 GB 與 128 GB。

硬體需求指南

要回舊版

v0.3.0（2026-10-14 發布，內嵌平台 1.73.1）與更早的版本仍然留在 Releases，資產與驗簽方式相同。已經成功開過 v0.4.0 的裝置不能經 A/B 更新退回這些版本。
