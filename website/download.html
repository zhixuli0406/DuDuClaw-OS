兩種版本、兩種形式、兩個機器目標，一共六個資產。每個資產都附同名的 .sha256 與 .minisig，燒錄前請自己驗一次。

2026-09-09 發布 內嵌平台 1.63.0 Linux 6.18 Yocto Project 6.0 「wrynose」 Apache-2.0

下載前先知道這幾件事

  • 0.2.0 是 bring-up 版本，1.0.0 才是第一個 GA。拿來當生產環境的唯一一台機器並不合適。
  • 所有驗證都在 QEMU 完成，尚未在真實 x86-64 硬體上開機過。duduclaw-genericx86-64 只做過設定稽核。
  • 映像未簽章，安裝前要在韌體裡關閉 Secure Boot。dm-verity 與 TPM 也還沒啟用。
  • 目標機需要 UEFI、支援 AVX2 的 x86-64 CPU 與一顆 SSD。arm64 機器（Apple Silicon、樹莓派）不能用。

怎麼選

三句話決定

要一台日常在用的桌面

選桌面版的安裝器 ISO（installer-desktop）。燒進 USB，開機跑圖形安裝精靈，選碟、確認、寫入、重開。

只要無頭的 gateway 值班機

選基礎版的安裝器 ISO（installer）。同樣的 A/B 佈局與桌面殼加 gateway，沒有應用層。這是 bring-up 產物。

想直接寫進整顆碟

選桌面版的整碟映像（.wic.zst）。解壓之後 dd 或 bmaptool 寫進目標硬碟，跳過安裝精靈。

機器維度也要選對：duduclaw-qemux86-64 是 QEMU bring-up 目標，兩種形式都實際開機驗證過；duduclaw-genericx86-64 是真實硬體目標，目前只做過設定稽核，在 QEMU 上開不起來。

先驗簽再燒

確認你拿到的就是我們發布的

檔案是從 GitHub 的伺服器下載的。驗簽是你自己確認手上這份位元組，就是我們簽出去的那一份。

minisign 公鑰

六個資產同一把公鑰，這裡釘死。

RWQyI00ugZ/+WVisQ2ZnKeTqFs8Ze8h2X11FO9Z8le0YubFMXYTwQD7n

驗簽章

把 <檔案> 換成你下載的檔名，同目錄要有對應的 .minisig。

minisign -V -P RWQyI00ugZ/+WVisQ2ZnKeTqFs8Ze8h2X11FO9Z8le0YubFMXYTwQD7n -m <檔案>

驗 SHA-256

同目錄要有對應的 .sha256。Linux 上把 shasum -a 256 換成 sha256sum。

shasum -a 256 -c <檔案>.sha256
燒錄

寫進 USB 或硬碟

dd 會把目標裝置整個覆蓋掉。下指令之前先用 lsblk 或 diskutil list 確認 /dev/sdX 是你要寫的那一顆。

安裝器 ISO 寫進 USB

或者用 balenaEtcher 這類圖形工具，選檔案、選隨身碟、按開始。

dd if=duduclaw-os-installer-desktop-duduclaw-genericx86-64-v0.2.0.iso \
   of=/dev/sdX bs=4M conv=fsync status=progress

整碟映像寫進硬碟

先解壓再寫。用 bmaptool copy 也可以，會跳過空區塊。

zstd -d duduclaw-os-duduclaw-genericx86-64-v0.2.0.wic.zst
dd if=duduclaw-os-duduclaw-genericx86-64-v0.2.0.wic \
   of=/dev/sdX bs=4M conv=fsync status=progress
  1. zstd 視窗參數：映像用 --long=27 壓縮。新版 zstd 解壓不必加參數；舊版如果提示視窗不足，解壓時補上 --long=27。
  2. 目標機開機設定：韌體切到 UEFI 開機，並且關閉 Secure Boot。v0.2.0 的映像沒有簽章。
  3. 安裝流程：ISO 開機後是圖形安裝精靈，選碟、確認、看寫入進度、重開。第一次開機接著跑首次設定精靈。
硬體

三個硬性條件

x86-64 且支援 AVX2

Intel Haswell（2013 年）以後、Intel N100 / N200 / N305、AMD Excavator（2015 年）以後與 Zen 全系。arm64 機器不能用。

UEFI 開機

安裝前在韌體裡關閉 Secure Boot。

SSD

最低 4 GB 記憶體與 64 GB SSD；建議 8 GB 與 128 GB。
